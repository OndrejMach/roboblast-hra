# roboblast-hra
Hraješ jako robot na 2D aréně. Pohybuješ se klávesnicí, míříš myší a střílíš kliknutím. Přicházejí vlny nepřátel — čím víc zabiješ, tím těžší nepřátelé přicházejí. Po 30 zabitích přejdeš na nový sektor (jiné prostředí, jiná hudba, větší tempo). Po 10 sektorech přijde MEGA-BOSS — finální bitva. Pokud ho porazíš, vyhraješ.
